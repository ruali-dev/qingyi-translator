# v0.2.5 · 论文 LaTeX 公式渲染

- 翻译框支持离线渲染行内与独立公式，包括分式、上下标、根号、积分、求和、矩阵、分段函数和多行对齐。
- 支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 及常见公式环境。
- 保留公式中的换行与命令；复制译文和选区时保留 LaTeX 源码。
- 后台渲染，公式随窗口宽度缩放；无法解析的公式保留源码，避免影响其余译文。
- 内置渲染库与公式字体，无需安装 LaTeX，也无需在线公式服务。

可直接覆盖升级 `Qingyi.exe`，保留现有设置和 API Key。旧版 Zotero 连接器兼容此修复；本次亦提供版本同步的 `qingyi-zotero.xpi`。

公式支持常见数学语法，不包含自定义宏或完整 LaTeX 文档，也无法恢复 PDF 选区缺失的公式结构。
