# v0.2.4 · 可调整大小的翻译窗口

## 更新内容

- 翻译结果窗口现在支持拖动右下角自由调整大小。
- 卡片背景、正文和滚动区域会随窗口尺寸动态重排。
- 扩大窗口移动热区，顶部图标、标题、状态和模型标签均可用于拖动。
- 再次唤起翻译窗口时会保留上次调整后的尺寸。
- 补充窗口尺寸边界与布局测试。

现有配置与 API Key 存储方式没有变化，可以直接覆盖升级。已安装旧版 Zotero 连接器的用户可以重新安装本次 Release 中的 `qingyi-zotero.xpi` 完成版本同步。

## 下载

- `Qingyi.exe`：Windows 桌面端。
- `qingyi-zotero.xpi`：Zotero 10 连接器。
